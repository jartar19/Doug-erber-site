# Douglas Erber · personal site

Static one-page site for Douglas Erber, nonprofit executive director (Long Beach, CA).

- `index.html` holds all markup, CSS and JS (GSAP, ScrollTrigger and Lenis load from CDNs).
- `assets/hero-orbit.mp4` is the scroll-scrubbed hero clip (H.264, every frame a keyframe). `assets/hero-poster.jpg` is its first frame.
- `BUILD-PLAN.md` is the full brief, style guide and build notes. It is not served (see `.vercelignore`).

Hosting: Vercel project `doug-erber-site`, framework preset "Other", no build step.
Live: https://doug-erber-site.vercel.app
